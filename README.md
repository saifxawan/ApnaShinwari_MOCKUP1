# ApnaShinwari_MOCKUP1

Auténtica Comida de India y Pakistán - Halal
**Apna Shinwari Pak-Ind Restaurant** (Plaza Clavé 21, Castellón de la Plana, España).

## Características
- **Diseño Moderno & Moody**: Interfaz oscura de alta fidelidad basada en diseño para restaurantes prémium.
- **100% Responsivo & Optimizado para iPhone**: Soporte nativo para safe areas (notch, Dynamic Island, home bar), prevención de zoom automático en iOS Safari y botones adaptados a pantallas táctiles.
- **Menú Interactivo & Carrusel 3D**: Carrusel táctil con gestos swipe para platos estrella (Karahi de Pollo 1KG, Cordero Karahi, Pollo Biryani) y barra de categorías con scroll horizontal.
- **Gestión de Pedido (Carrito Desplegable)**: Carrito lateral en tiempo real con cálculo dinámico de subtotales.
- **Reserva de Mesa**: Formulario interactivo con validación y modal de confirmación con localizador.

## Tecnologías
- HTML5 semántico
- CSS3 puro (Grid, Flexbox, variables CSS, Media Queries modernas)
- JavaScript Vanilla (cero dependencias externas)
